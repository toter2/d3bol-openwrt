# 🚀 D3BOL OpenWrt Repository

مستودع حزم تابعة لدعبول ستور مخصصة لتشغيل وتسهيل إدارة أدوات الشبكات وتجاوز الحجب على الراوترات (يدعم إصدارات OpenWrt 24.10 و 25).

</div>

---

## 📦 الحزم المتوفرة في المستودع

| اسم الحزمة | الوصف والوظيفة |
| :--- | :--- |
| **D3BOL-PANEL** | لوحة التحكم والتحكم السريع بالأدوات عبر المتصفح. |
| **luci-app-d3bol-split** | واجهة رسومية (LuCI) مدمجة لإدارة توجيه الشبكات وحركة المرور. |
| **d3bol-xray-lite** | حزمة الاتصال السريعة وخفيفة الوزن لتجاوز الحجب وتشغيل بروتوكولات VLESS. |

---
