D3BOL OpenWrt

مستودع حزم دعبول ستور للراوترات

تنصيب بأمر واحد

من SSH على الراوتر (OpenWrt 24.10 أو 25):

wget -qO- @BASE@/install.sh | sh

يضيف المستودع ومفتاح التوقيع، وينصّب اللوحة والعزل والنواة الخفيفة. التحديثات بعدها بـ apk upgrade أو opkg upgrade.

الحزم

  • d3bol-panel — لوحة xray بيوزر وباسورد على 2017، بروكسي شفاف، سيرفرات واشتراكات، HTTP Ping
  • luci-app-d3bol-split — عزل التطبيقات: تطبيقات تطلع مباشر بدون VPN
  • d3bol-xray-lite — xray 1.8.24: أقل رام ومعالج، ويقبل vless بدون TLS

الأجهزة: aarch64_cortex-a53 (GL-MT6000، Linksys MX2000…) و x86_64 (Mini PC). اللوحة والعزل تشتغل على كل الأجهزة.

تنصيب يدوي

OpenWrt 25 (apk):

wget -qO /etc/apk/keys/d3bol.pem @BASE@/keys/d3bol.pem
echo "@BASE@/apk/$(cat /etc/apk/arch)/packages.adb" > /etc/apk/repositories.d/d3bol.list
apk update && apk add d3bol-panel luci-app-d3bol-split d3bol-xray-lite
