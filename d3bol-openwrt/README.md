# 🚀 D3BOL OpenWrt Repository

مستودع حزم تابعة لـ **دعبول ستور** مخصصة لتشغيل وتسهيل إدارة أدوات الشبكات وتجاوز الحجب على الراوترات (يدعم إصدارات **OpenWrt 24.10** و **25**).

---

## 📦 الحزم المتوفرة في المستودع

| اسم الحزمة | الوصف والوظيفة |
| :--- | :--- |
| **`d3bol-panel`** | لوحة تحكم متكاملة بيوزر وباسورد (تعمل على المنفذ `2017` كبديل لـ `v2rayA`). تدعم بروكسي شفاف، إدارة السيرفرات والاشتراكات، فحص السرعة (HTTP Ping)، صفحة LuCI، وتدعم نواتي `xray` و `sing-box` (يتم اختيار الأخير تلقائياً إذا كان منصباً)[cite: 1]. |
| **`luci-app-d3bol-split`** | أداة عزل وتوجيه التطبيقات؛ لتوجيه تطبيقات معينة لتخرج مباشرة على خط الإنترنت الأساسي بدون VPN[cite: 1]. |
| **`d3bol-xray-lite`** | نواة `xray dev` خفيفة ومضغوطة تعمل مباشرة من الذاكرة (RAM) بأقل استهلاك ممكن، مع دعم روابط `vless` مباشرة بدون الحاجة لـ TLS. |

---
